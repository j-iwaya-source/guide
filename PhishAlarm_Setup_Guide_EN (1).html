Overview: What is PhishAlarm?

📧
① User receives a suspicious email
Phishing, spam, spoofed sender, etc.
↓ One click
🎣
② Click "Report Phish" button in Gmail
Button always visible in the email toolbar
↓ Auto-forwarded
🛡️
③ Auto-forwarded to IT team + threat scoring via Analyzer
Email type auto-classified and routed to the appropriate team

📌 Auto-Classification of Reported Emails (4 Types)

🚨 Potential Phish
Actual suspicious email. Forwarded to the incident response / IT team.
🎯 Simulated Phish
Phishing simulation email. Forwarded to IT / security education team.
📚 ZenGuide Email
Training notification from ZenGuide platform. Forwarded for review.
✅ Safelist Email
Email from a pre-approved safe address. Forwarded for review.
⚠️ Gmail Limitation: Auto-deletion or auto-move to spam after reporting is NOT supported. The email remains in the inbox. Please instruct users to delete it manually.

Pre-Authorize ZenGuide in Google Admin Console (Recommended)

approx. 10 min
💡 Completing this step prevents users from seeing an authorization popup when using PhishAlarm for the first time. This step is optional but strongly recommended.

📌 Perform these steps in Google Admin Console (admin.google.com)

Google Admin Console
👤 Users
🛡️ Security ←
📱 Devices
① Log in to Google Admin Console (admin.google.com) and navigate to "Security" → "Access and data control" → "API controls".
↓
Manage Third-Party App Access
+ Add App ←
② Click "Manage Third-Party App Access", then "Add App" → "OAuth App Name or Client ID".
↓
ZenGuide Security Select ←
③ Search for "ZenGuide", click "Select" on the result, check both OAuth Client IDs, then click "Select".
↓
App Access
Restricted
Trusted ←
Can access all Google services
④ Under App Access, select "Trusted: Can access all Google services" and click "Configure".
✅ Authorization complete! Users will no longer see the permission popup on first use.

Verification & Firewall / Allowlist Settings

approx. 5 min

1

2

3
Click the button and confirm the confirmation dialog appears.
4

5
Confirm the reported email was received at the forwarding address (phishalarm@adventure-inc.co.jp).
Button not showing up?
Check that the user's email address is registered in ZenGuide User Management. The button only appears for users with an active license.
② Allowlist URLs (Asia Pacific Region)
⚠️ If you use a proxy or firewall, please allowlist the following URLs. For Adventure Inc., the AP (Asia Pacific) region is most likely applicable.
https://phishalarm-ap-southeast-2.securityeducation.com/api/v1/
https://phishalarm-ap.securityeducation.com
https://analyzer-api.ap.securityeducation.com

② Common Support Questions
Q. Is this a phishing simulation email?
→ "Thank you for reporting! This was a simulated phishing email sent as part of our security awareness training. Great job catching it! 👏"
※ Add: "Please don't share this with other team members."
Q. The button is not showing up.
→ Make sure Gmail is open in a desktop browser (Chrome recommended). The button is not supported in mobile web browsers.
Q. The email didn't move to spam after I reported it.
→ Auto-move to spam is not supported in the Gmail version. Please move it to spam or delete it manually.
