🔍 Explanation of Changes

Parameter Before After Reason
SPF tail -all ip4:52.194.41.164 -all Allows mail from the Zabbix proxy server (mail01) to pass SPF. IP confirmed as "zabbixプロキシ" in the Google Cloud Armor IP registry. The -all strict policy is retained.
p= p=none (monitor only) p=quarantine (quarantine) FAIL messages will be delivered to the spam folder instead of the inbox. All legitimate senders are confirmed PASS, so no impact on normal mail flow.
pct= (not set = 100%) pct=10 Policy applies to only 10% of FAIL messages. Staged rollout to minimize risk. Will increase to pct=100 after one week of stable operation.
sp= (not set) sp=none Subdomains (e.g. skyticket.com) are exempt from the policy. Prevents unintended impact on subdomain mail flows.
aspf= / adkim= (not set = strict) aspf=r / adkim=r Relaxed alignment mode. Reduces false positives from forwarded mail and some third-party services.
⚠️ Important: Only ONE SPF record is allowed per domain
Edit and overwrite the existing SPF record. Do NOT add a new one — having two SPF records will break SPF authentication entirely.

Emergency Rollback Procedure

Emergency Use Only
⚠️ When to rollback
If you receive reports of legitimate mail landing in spam, or if DMARC reports reveal a newly discovered legitimate sender that is FAILING, immediately revert to p=none using the steps below.

🔁 Rollback steps

1
Log in to onamae.com Navi and navigate to DNS Record Settings.
2
Edit the _dmarc TXT record and replace the VALUE with:
v=DMARC1; p=none; rua=mailto:info-system@adventure-inc.co.jp
3
Click "Proceed to Confirmation" → "Apply Settings" to save.
4
After DNS propagation (up to TTL = 3600 seconds), verify that p=none is in effect via nslookup.
5
Identify the new FAIL sender(s) from DMARC reports, add the necessary SPF/DKIM settings, then attempt migration to p=quarantine again.
⚠️ The SPF change does NOT need to be rolled back
The addition of the Zabbix proxy IP (ip4:52.194.41.164) to SPF is permanent and should be retained even after rolling back the DMARC policy.
🆘 If you encounter issues during rollback, contact #help_社内システム on Slack immediately
